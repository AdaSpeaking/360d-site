# 360d 官網設計稿示意版

給內部看設計稿用的可點擊示意網站，不是正式官網。每一頁是 Figma 匯出的整頁圖，上面疊透明的連結區塊。

## 放上 GitHub Pages

1. 把這個資料夾裡的**所有東西**（36 個 `.html`、`assets/`、`img/`）上傳到 repo 的最上層。
2. repo 的 Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save。
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

## 想改的話

- 各類按鈕要連去哪（諮詢、試用、成功案例；「進一步瞭解」和「下載」目前留空）：打開 `assets/site.js`，改最上面的 `CONFIG`。
- 首頁「專屬需求提問」的題目、推薦服務、連結：都寫在 `assets/quiz.js` 最上面。
- 右下角「設計稿示意版」不要：同一個檔案把 `badge` 改成 `false`。
- 想看每個連結區塊的位置：網址後面加 `?debug=1`。

設計稿是 1920 寬的電腦版，用手機看字會很小。
